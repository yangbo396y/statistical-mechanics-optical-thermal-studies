# Statistical Mechanics, Optical and Thermal Studies

This repository collects a series of papers and notes on statistical mechanics, optical and thermal phenomena, phase cells, photon number, and the distinction between particle ontology and structure ontology.

The main purpose of this repository is to provide a public index for these works, including PDF files, Zenodo DOI links, and related information.
